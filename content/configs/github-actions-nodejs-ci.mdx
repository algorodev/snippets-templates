Drop this into `.github/workflows/ci.yml` to get lint, type checking, and tests running automatically on every push and pull request, with `node_modules` caching to keep runs fast.

## Usage

```yaml
name: CI

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  ci:
    name: Lint, Type Check & Test
    runs-on: ubuntu-latest

    strategy:
      matrix:
        node-version: [20.x]

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Set up Node.js ${{ matrix.node-version }}
        uses: actions/setup-node@v4
        with:
          node-version: ${{ matrix.node-version }}

      - name: Cache node_modules
        uses: actions/cache@v4
        with:
          path: node_modules
          key: ${{ runner.os }}-node-${{ matrix.node-version }}-${{ hashFiles('**/package-lock.json') }}
          restore-keys: |
            ${{ runner.os }}-node-${{ matrix.node-version }}-
            ${{ runner.os }}-node-

      - name: Install dependencies
        run: npm ci

      - name: Lint
        run: npm run lint

      - name: Type check
        run: npm run typecheck

      - name: Test
        run: npm test
```

## Options

| Field | Default | Effect |
|-------|---------|--------|
| `on.push.branches` | `[main]` | Branches that trigger a push-based run |
| `on.pull_request.branches` | `[main]` | Target branches that trigger a PR-based run |
| `matrix.node-version` | `[20.x]` | Node version(s) to test against — add more to test multiple versions |
| `cache.key` | `hashFiles('**/package-lock.json')` | Change to `yarn.lock` or `pnpm-lock.yaml` for other package managers |

## Notes

- The cache key is keyed to `package-lock.json` so the cache invalidates whenever dependencies change. Adjust the path and key for Yarn (`yarn.lock`) or pnpm (`pnpm-lock.yaml`).
- To test against multiple Node versions, extend the matrix: `node-version: [18.x, 20.x, 22.x]`.
- Make sure your `package.json` has `lint`, `typecheck`, and `test` scripts. Common setups use `tsc --noEmit` for `typecheck` and `vitest` or `jest` for `test`.
- Add `--if-present` (e.g. `npm run lint --if-present`) to skip steps gracefully if a script is not defined.
