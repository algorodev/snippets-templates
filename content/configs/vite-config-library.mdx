Build a dual-format (ESM + CJS) library with Vite's built-in library mode. Peer dependencies are externalized so they are never bundled into the output, and `vite-plugin-dts` generates `.d.ts` declaration files automatically.

## Usage

```javascript
// vite.config.js
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import dts from 'vite-plugin-dts'
import { resolve } from 'path'
import { readFileSync } from 'fs'

const pkg = JSON.parse(readFileSync('./package.json', 'utf-8'))

// Collect all peer dependencies and dependencies to externalize
const external = [
  ...Object.keys(pkg.peerDependencies ?? {}),
  ...Object.keys(pkg.dependencies ?? {}),
]

export default defineConfig({
  plugins: [
    react(),
    dts({
      insertTypesEntry: true,
      include: ['src'],
    }),
  ],

  build: {
    lib: {
      entry: resolve(__dirname, 'src/index.ts'),
      name: 'MyLibrary',
      formats: ['es', 'cjs'],
      fileName: (format) => `index.${format === 'es' ? 'mjs' : 'cjs'}`,
    },
    rollupOptions: {
      external,
      output: {
        // Preserve module directory structure in ESM output
        preserveModules: false,
        globals: {
          react: 'React',
          'react-dom': 'ReactDOM',
        },
      },
    },
    sourcemap: true,
    // Emit declaration files alongside JS
    emptyOutDir: true,
  },
})
```

**`package.json` exports field:**

```json
{
  "name": "my-library",
  "version": "1.0.0",
  "main": "./dist/index.cjs",
  "module": "./dist/index.mjs",
  "types": "./dist/index.d.ts",
  "exports": {
    ".": {
      "import": "./dist/index.mjs",
      "require": "./dist/index.cjs",
      "types": "./dist/index.d.ts"
    }
  },
  "files": ["dist"],
  "peerDependencies": {
    "react": "^18.0.0",
    "react-dom": "^18.0.0"
  },
  "devDependencies": {
    "vite": "^5.0.0",
    "@vitejs/plugin-react": "^4.0.0",
    "vite-plugin-dts": "^3.0.0",
    "typescript": "^5.0.0"
  }
}
```

**Install:**

```bash
npm install -D vite @vitejs/plugin-react vite-plugin-dts typescript
```

## Options

| Field | Default | Effect |
|-------|---------|--------|
| `build.lib.entry` | required | Entry point for the library bundle |
| `build.lib.formats` | `['es', 'umd']` | Output formats to generate |
| `build.lib.fileName` | auto | File name template for each format |
| `rollupOptions.external` | `[]` | Module IDs that must not be bundled |
| `dts.insertTypesEntry` | `false` | Adds a barrel `index.d.ts` at the output root |
| `dts.include` | — | Glob patterns for source files to include in type generation |

## Notes

- Reading `peerDependencies` and `dependencies` from `package.json` at build time ensures the `external` list stays in sync automatically — no need to maintain a separate array.
- Use `formats: ['es', 'cjs']` rather than `['es', 'umd']` for Node-consumed libraries; UMD is primarily needed for browser `<script>` tag usage.
- The `exports` field in `package.json` is required for Node's dual-package hazard to be handled correctly — bundlers and runtimes use it to pick the right format.
- If you do not use React, remove `@vitejs/plugin-react`, the `react` plugin call, and the `globals` block.
