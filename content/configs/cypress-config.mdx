Configures Cypress for both component and end-to-end test modes with TypeScript, sensible viewport defaults, and a custom commands file ready to extend.

## Usage

```javascript
// cypress.config.js
import { defineConfig } from 'cypress';

export default defineConfig({
  e2e: {
    baseUrl: 'http://localhost:3000',
    specPattern: 'cypress/e2e/**/*.cy.{js,jsx,ts,tsx}',
    supportFile: 'cypress/support/e2e.ts',
    videosFolder: 'cypress/videos',
    screenshotsFolder: 'cypress/screenshots',
    video: false,
    screenshotOnRunFailure: true,
    viewportWidth: 1280,
    viewportHeight: 720,
    defaultCommandTimeout: 6000,
    requestTimeout: 10000,
    responseTimeout: 30000,
    retries: {
      runMode: 2,
      openMode: 0,
    },
    env: {
      apiUrl: 'http://localhost:3000/api',
    },
    setupNodeEvents(on, config) {
      // Register node event listeners here
      on('task', {
        log(message) {
          console.log(message);
          return null;
        },
      });
      return config;
    },
  },
  component: {
    devServer: {
      framework: 'react',
      bundler: 'vite',
    },
    specPattern: 'src/**/*.cy.{js,jsx,ts,tsx}',
    supportFile: 'cypress/support/component.ts',
    viewportWidth: 800,
    viewportHeight: 600,
  },
});
```

**Support file (`cypress/support/e2e.ts`):**

```typescript
// cypress/support/e2e.ts
import './commands';

// Silence uncaught exception errors from third-party scripts
Cypress.on('uncaught:exception', (err) => {
  if (err.message.includes('ResizeObserver loop')) return false;
  return true;
});
```

**Custom commands (`cypress/support/commands.ts`):**

```typescript
// cypress/support/commands.ts
/// <reference types="cypress" />

declare global {
  namespace Cypress {
    interface Chainable {
      login(email: string, password: string): Chainable<void>;
      dataCy(value: string): Chainable<JQuery<HTMLElement>>;
    }
  }
}

Cypress.Commands.add('login', (email, password) => {
  cy.session([email, password], () => {
    cy.visit('/login');
    cy.get('[data-cy=email]').type(email);
    cy.get('[data-cy=password]').type(password);
    cy.get('[data-cy=submit]').click();
    cy.url().should('not.include', '/login');
  });
});

Cypress.Commands.add('dataCy', (value) => {
  return cy.get(`[data-cy=${value}]`);
});
```

**Install:**

```bash
npm install -D cypress
npx cypress open
```

**Add scripts to `package.json`:**

```json
{
  "scripts": {
    "cy:open": "cypress open",
    "cy:run": "cypress run",
    "cy:run:e2e": "cypress run --e2e",
    "cy:run:component": "cypress run --component"
  }
}
```

## Options

| Field | Value | Effect |
|-------|-------|--------|
| `baseUrl` | string | Prepended to all `cy.visit()` calls |
| `viewportWidth` / `viewportHeight` | number | Default browser window size |
| `defaultCommandTimeout` | ms | How long to wait for DOM queries to succeed |
| `retries.runMode` | number | Automatic retries in `cypress run` (CI) |
| `retries.openMode` | number | Retries in interactive `cypress open` mode |
| `video` | `false` \| `true` | Whether to record MP4 videos of test runs |

## Notes

- Use `cy.session()` inside custom login commands to cache auth state across tests and avoid repeating the full login flow.
- The `dataCy` custom command standardizes selection via `data-cy` attributes, keeping tests decoupled from CSS class changes.
- Set `video: false` locally and enable it only on CI to save disk space during development.
- For TypeScript support, add `"types": ["cypress"]` to your `tsconfig.json` `compilerOptions`.
