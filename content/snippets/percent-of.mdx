Computes what percentage `value` is of `total`, returning a number between `0` and `100` (or beyond those bounds if clamping is disabled). Returns `0` safely when `total` is zero.

## Usage

```typescript
function percentOf(value: number, total: number, clamp: boolean = false): number {
  if (total === 0) return 0
  const result = (value / total) * 100
  if (clamp) return Math.min(100, Math.max(0, result))
  return result
}

export default percentOf
```

## Options

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `value` | `number` | — | The part to measure |
| `total` | `number` | — | The whole to measure against |
| `clamp` | `boolean` | `false` | Restrict the result to the 0–100 range |

## Examples

```typescript
percentOf(25, 200)         // 12.5
percentOf(1, 3)            // 33.333333333333336
percentOf(200, 100)        // 200     (over 100%, unclamped)
percentOf(200, 100, true)  // 100     (clamped)
percentOf(-10, 100, true)  // 0       (clamped below 0)
percentOf(50, 0)           // 0       (division by zero guard)
```

## Notes

- The unclamped default is intentional — progress bars and loading indicators may legitimately exceed 100% (e.g. file uploads that overshoot an estimate).
- To format the result for display, pair it with `toFixed`: `percentOf(1, 3).toFixed(1) + '%'` → `"33.3%"`.
- For the inverse operation (finding the value that corresponds to a given percentage of a total), use `(percent / 100) * total`.
