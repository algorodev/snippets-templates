Computes the standard deviation of a numeric array in a single pass for the mean and a second pass for the squared differences. Supports both population (`N`) and sample (`N-1`) variants via a flag.

## Usage

```typescript
function standardDeviation(values: number[], sample: boolean = false): number | undefined {
  if (values.length === 0) return undefined
  if (values.length === 1) return 0

  const n = values.length
  const mean = values.reduce((sum, v) => sum + v, 0) / n
  const squaredDiffs = values.reduce((sum, v) => sum + (v - mean) ** 2, 0)
  const divisor = sample ? n - 1 : n

  return Math.sqrt(squaredDiffs / divisor)
}

export default standardDeviation
```

## Options

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `values` | `number[]` | — | The dataset |
| `sample` | `boolean` | `false` | Use sample std dev (`N-1`) instead of population (`N`) |

## Examples

```typescript
standardDeviation([2, 4, 4, 4, 5, 5, 7, 9])        // 2        (population)
standardDeviation([2, 4, 4, 4, 5, 5, 7, 9], true)   // 2.138...  (sample)
standardDeviation([10, 10, 10])                      // 0        (no variance)
standardDeviation([42])                              // 0        (single element)
standardDeviation([])                                // undefined
```

## How it works

1. **Mean** — sum all values and divide by `n`.
2. **Sum of squared differences** — for each value, compute `(value - mean)²` and sum the results.
3. **Variance** — divide by `n` (population) or `n - 1` (sample, Bessel's correction).
4. **Standard deviation** — take the square root of the variance.

## Notes

- Use **population** (`sample: false`) when your array contains the entire dataset (e.g. pixel intensities of a known image).
- Use **sample** (`sample: true`) when your array is a subset drawn from a larger population and you want an unbiased estimate (e.g. survey responses, A/B test measurements). Bessel's correction (`N-1`) compensates for the tendency of a sample to underestimate variance.
- For very large arrays or high-frequency calls, consider Welford's online algorithm, which computes the mean and variance in a single pass without storing all values.
