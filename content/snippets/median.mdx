Finds the median of a numeric array by sorting a copy of the input and selecting the middle value (odd length) or averaging the two middle values (even length). Returns `undefined` for empty arrays instead of `NaN`.

## Usage

```typescript
function median(values: number[]): number | undefined {
  if (values.length === 0) return undefined

  const sorted = [...values].sort((a, b) => a - b)
  const mid = Math.floor(sorted.length / 2)

  return sorted.length % 2 !== 0
    ? sorted[mid]
    : (sorted[mid - 1] + sorted[mid]) / 2
}

export default median
```

## Examples

```typescript
median([3, 1, 4, 1, 5])        // 3       (odd length — middle element)
median([1, 2, 3, 4])           // 2.5     (even length — average of 2 and 3)
median([42])                   // 42      (single element)
median([5, 5, 5])              // 5       (all equal)
median([-3, -1, 0, 1, 3])      // 0       (includes negatives)
median([])                     // undefined
```

## How it works

1. A shallow copy (`[...values]`) is sorted numerically to avoid mutating the original array.
2. For an **odd** number of elements, the exact middle index (`Math.floor(length / 2)`) is returned.
3. For an **even** number of elements, the two values straddling the midpoint are averaged.

## Notes

- The original array is never mutated — sorting is done on a copy.
- The explicit numeric comparator `(a, b) => a - b` is required because the default `Array.prototype.sort` compares elements as strings, which produces incorrect results for numbers (e.g. `[10, 9, 2]` would sort as `[10, 2, 9]`).
- For large arrays called in a hot path, consider pre-sorting the data upstream to avoid the repeated `O(n log n)` sort.
