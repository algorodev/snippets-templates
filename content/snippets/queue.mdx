Serialises async work so tasks never run in parallel, preventing race conditions when order matters or a shared resource can only handle one operation at a time.

## Usage

```typescript
type Task<T> = () => Promise<T>

class AsyncQueue {
  private queue: Array<() => void> = []
  private running = false

  get size(): number {
    return this.queue.length
  }

  enqueue<T>(task: Task<T>): Promise<T> {
    return new Promise<T>((resolve, reject) => {
      this.queue.push(async () => {
        try {
          resolve(await task())
        } catch (err) {
          reject(err)
        }
      })

      if (!this.running) {
        this.run()
      }
    })
  }

  drain(): Promise<void> {
    if (!this.running && this.queue.length === 0) {
      return Promise.resolve()
    }

    return new Promise(resolve => {
      const original = this.run.bind(this)

      const check = () => {
        if (this.queue.length === 0 && !this.running) {
          resolve()
        }
      }

      // Poll via a lightweight sentinel task
      this.enqueue(() => Promise.resolve()).then(check)
    })
  }

  private async run(): Promise<void> {
    this.running = true

    while (this.queue.length > 0) {
      const task = this.queue.shift()!
      await task()
    }

    this.running = false
  }
}

export { AsyncQueue }
export type { Task }
```

## Examples

```typescript
const queue = new AsyncQueue()

// Enqueue work — each task starts only after the previous one resolves
queue.enqueue(() => writeFile('log.txt', 'line 1\n'))
queue.enqueue(() => writeFile('log.txt', 'line 2\n'))
queue.enqueue(() => writeFile('log.txt', 'line 3\n'))

// Await a specific result
const id = await queue.enqueue(() => db.insert({ name: 'Alice' }))
console.log('Inserted with id:', id)

// Wait for all queued work to finish
await queue.drain()
console.log('All tasks complete, queue size:', queue.size) // 0

// Error handling — one failing task does not stop the queue
queue.enqueue(() => Promise.reject(new Error('oops'))).catch(console.error)
queue.enqueue(() => sendEmail('done@example.com')) // still runs
```

## API

| Member | Type | Description |
|---|---|---|
| `enqueue(task)` | `Promise<T>` | Adds a task to the end of the queue and returns its result promise |
| `drain()` | `Promise<void>` | Resolves when the queue empties and the last task finishes |
| `size` | `number` | Number of tasks currently waiting (does not count the running task) |

## How it works

A single `run` loop pulls tasks off the front of an array one at a time, awaiting each before dequeuing the next. Because `running` is set to `true` for the duration of the loop, any task added while work is in progress simply pushes onto the array and is picked up automatically — no second loop is ever started.
