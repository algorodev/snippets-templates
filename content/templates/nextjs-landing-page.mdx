## Usage

```typescript
// app/page.tsx

import { Features } from "@/components/landing/features";
import { Pricing } from "@/components/landing/pricing";
import { Testimonials } from "@/components/landing/testimonials";
import { CTA } from "@/components/landing/cta";

  return (
    <main>
      <Hero />
      <Features />
      <Pricing />
      <Testimonials />
      <CTA />
    </main>
  );
}
```

## Options

| Section | File | Key props to edit |
|---|---|---|
| Hero | `components/landing/hero.tsx` | headline, subtext, CTA links |
| Features | `components/landing/features.tsx` | `features` array (icon, title, description) |
| Pricing | `components/landing/pricing.tsx` | `plans` array (price, features, CTA href) |
| Testimonials | `components/landing/testimonials.tsx` | `testimonials` array |
| CTA | `components/landing/cta.tsx` | headline, body copy, button href |

## Notes

- All animations use `whileInView` with `once: true` so they only play once as sections scroll into view.
- Dark mode is handled via Tailwind's `dark:` variant — add `darkMode: "class"` to `tailwind.config.ts` and toggle the `dark` class on `<html>`.
- Replace `i.pravatar.cc` avatar URLs with real user photos before going live.

## README

### What this includes

- Hero section with animated headline, badge, and dual CTAs
- Animated feature grid (4-up, staggered scroll reveal)
- 3-tier pricing table with highlighted recommended plan
- Testimonials section with avatar, name, and role
- Full-bleed CTA banner
- Framer Motion scroll animations throughout
- Tailwind CSS v3 dark mode support
- TypeScript throughout with no `any` types

### Prerequisites

- Node.js 18+
- A Next.js App Router project (`npx create-next-app@latest`)

### Create this template

```bash
npx create-next-app@latest my-landing --typescript --tailwind --eslint --app --src-dir no
cd my-landing

# Install animation and icon dependencies
npm install framer-motion lucide-react

# Create component directories
mkdir -p components/landing

# Create section components
touch components/landing/hero.tsx
touch components/landing/features.tsx
touch components/landing/pricing.tsx
touch components/landing/testimonials.tsx
touch components/landing/cta.tsx

# Wire up the page
# Edit app/page.tsx to import and render all five components
npm run dev
```

### Project structure

```
app/
  page.tsx                  # Imports and renders all landing sections
  layout.tsx                # Root layout, font, metadata
components/
  landing/
    hero.tsx                # Hero section with animated headline
    features.tsx            # Feature grid with stagger animation
    pricing.tsx             # 3-tier pricing cards
    testimonials.tsx        # Social proof with avatars
    cta.tsx                 # Bottom call-to-action banner
public/
  og.png                    # Open Graph image (1200x630)
```

### First things to customize

- **`components/landing/hero.tsx`** — update headline, sub-copy, badge text, and CTA `href` values
- **`components/landing/features.tsx`** — replace the `features` array with your product's actual differentiators
- **`components/landing/pricing.tsx`** — update plan names, prices, and feature lists; wire `href` to your checkout flow
- **`components/landing/testimonials.tsx`** — swap placeholder quotes and avatars for real customer quotes
- **`app/layout.tsx`** — update `metadata.title`, `metadata.description`, and `openGraph.images`
- **`tailwind.config.ts`** — add `darkMode: "class"` and your brand color palette under `theme.extend.colors`
