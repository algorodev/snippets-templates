A production-ready scaffold for building and shipping a reusable React component library — Vite in library mode generates ESM and CJS bundles with declaration files, Storybook provides an isolated development environment, and Changesets automates semantic versioning and changelog generation on every merge to main.

## Usage

```bash
# Install and run Storybook during development
npm install
npm run storybook

# Build the distributable library
npm run build

# Bump version and generate changelog
npx changeset
npx changeset version
npm publish
```

## Vite library config

```typescript
// vite.config.ts
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";
import dts from "vite-plugin-dts";
import { resolve } from "path";

export default defineConfig({
  plugins: [
    react(),
    dts({
      insertTypesEntry: true,
      include: ["src/lib"],
    }),
  ],
  build: {
    lib: {
      entry: resolve(__dirname, "src/lib/index.ts"),
      name: "MyComponentLibrary",
      formats: ["es", "cjs"],
      fileName: (format) => `index.${format === "es" ? "mjs" : "cjs"}`,
    },
    rollupOptions: {
      // Treat React as a peer dependency — do not bundle it
      external: ["react", "react-dom", "react/jsx-runtime"],
      output: {
        globals: {
          react: "React",
          "react-dom": "ReactDOM",
        },
      },
    },
    sourcemap: true,
    emptyOutDir: true,
  },
});
```

## Example component

```typescript
// src/lib/components/Button/Button.tsx
import type { ButtonHTMLAttributes, ReactNode } from "react";
import styles from "./Button.module.css";

export type ButtonVariant = "primary" | "secondary" | "ghost";
export type ButtonSize = "sm" | "md" | "lg";

export interface ButtonProps extends ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: ButtonVariant;
  size?: ButtonSize;
  loading?: boolean;
  children: ReactNode;
}

export function Button({
  variant = "primary",
  size = "md",
  loading = false,
  disabled,
  children,
  className,
  ...props
}: ButtonProps) {
  return (
    <button
      {...props}
      disabled={disabled || loading}
      className={[
        styles.button,
        styles[variant],
        styles[size],
        loading ? styles.loading : "",
        className,
      ]
        .filter(Boolean)
        .join(" ")}
    >
      {loading ? <span className={styles.spinner} aria-hidden /> : null}
      {children}
    </button>
  );
}
```

## Changesets workflow

```bash
# 1. After making changes, create a changeset describing what changed
npx changeset
# Select packages, choose bump type (major/minor/patch), write a summary

# 2. On the release branch, apply all pending changesets
npx changeset version
# This bumps package.json versions and updates CHANGELOG.md

# 3. Publish to npm
npm run build
npm publish
```

## README

### What this includes

- **Vite library mode** — Dual ESM + CJS output with TypeScript declaration files via `vite-plugin-dts`
- **React** as a peer dependency — not bundled into the output
- **Storybook 8** — Isolated component development with `autodocs` and Controls addon
- **Changesets** — Semantic versioning, automated changelog, and npm publish workflow
- **CSS Modules** — Scoped styles that do not leak into consumer apps
- **TypeScript** — Strict mode, declaration files emitted to `dist/`
- **`package.json` exports map** — Correct ESM/CJS/types resolution for all module systems

### Prerequisites

- Node.js 18+
- npm account (for publishing) — run `npm login` before first publish

### Create this template

```bash
# 1. Create a new Vite project (React + TypeScript)
npm create vite@latest my-lib -- --template react-ts
cd my-lib

# 2. Install build and DTS dependencies
npm install -D vite-plugin-dts

# 3. Install Storybook
npx storybook@latest init

# 4. Install Changesets
npm install -D @changesets/cli
npx changeset init

# 5. Update vite.config.ts with the library mode config shown above

# 6. Update package.json with the exports map shown above

# 7. Create src/lib/index.ts as the library entry point

# 8. Start building components
npm run storybook
```

### First things to customize

- `package.json` — Set `name`, `version`, `description`, `repository`, `author`, and `license`
- `src/lib/index.ts` — Delete the `Button` exports and add your own components
- `.changeset/config.json` — Set `"access": "public"` if publishing a public scoped package
- `vite.config.ts` — Update `name` in the `lib` option to match your library's global name
- `README.md` — Replace the placeholder with real usage examples for your consumers
