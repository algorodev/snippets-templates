A production-ready Expo starter that gets you file-based routing (no navigator setup required), Tailwind-style utility classes via NativeWind, and EAS Build pre-configured for iOS and Android — all typed with TypeScript strict mode.

## Usage

```bash
# Install dependencies and start the dev server
npm install
npx expo start

# Open on device/simulator
# Press i → iOS simulator, a → Android emulator, w → web
```

## App entry and layout

```typescript
// app/_layout.tsx
import { Stack } from "expo-router";
import { StatusBar } from "expo-status-bar";
import "../global.css";

export default function RootLayout() {
  return (
    <>
      <StatusBar style="auto" />
      <Stack>
        <Stack.Screen name="(tabs)" options={{ headerShown: false }} />
        <Stack.Screen name="+not-found" />
      </Stack>
    </>
  );
}
```

## Tab navigator

```typescript
// app/(tabs)/_layout.tsx
import { Tabs } from "expo-router";
import { Ionicons } from "@expo/vector-icons";

export default function TabLayout() {
  return (
    <Tabs
      screenOptions={{
        tabBarActiveTintColor: "#6366f1",
        headerShown: false,
      }}
    >
      <Tabs.Screen
        name="index"
        options={{
          title: "Home",
          tabBarIcon: ({ color, size }) => (
            <Ionicons name="home-outline" size={size} color={color} />
          ),
        }}
      />
      <Tabs.Screen
        name="explore"
        options={{
          title: "Explore",
          tabBarIcon: ({ color, size }) => (
            <Ionicons name="search-outline" size={size} color={color} />
          ),
        }}
      />
    </Tabs>
  );
}
```

## README

### What this includes

- **Expo SDK 51+** — Managed workflow with OTA updates via Expo Updates
- **Expo Router v3** — File-based routing for screens, tabs, and modals
- **NativeWind v4** — Tailwind CSS utility classes for React Native components
- **TypeScript** — Strict mode with path aliases configured
- **EAS Build** — Development, preview, and production build profiles
- **SafeAreaContext** — Proper insets on iOS and Android
- **expo-status-bar** — Unified status bar control across platforms
- **Tab navigation** — Pre-configured bottom tab navigator with icons

### Prerequisites

- Node.js 18+
- Expo CLI: `npm install -g expo-cli` (or use `npx expo`)
- For iOS: Xcode 15+ with iOS Simulator
- For Android: Android Studio with an emulator configured
- EAS CLI for builds: `npm install -g eas-cli`

### Create this template

```bash
# 1. Create a new Expo app with the tabs template
npx create-expo-app@latest my-app --template tabs
cd my-app

# 2. Install NativeWind v4 and its peer dependencies
npx expo install nativewind tailwindcss react-native-reanimated react-native-safe-area-context

# 3. Generate tailwind.config.js
npx tailwindcss init

# 4. Update tailwind.config.js, babel.config.js, and app.config.js
#    as shown in the configuration sections above

# 5. Create global.css in the project root
#    (content shown in the NativeWind configuration section)

# 6. Import global.css in app/_layout.tsx

# 7. Install EAS CLI and configure builds
npm install -g eas-cli
eas login
eas build:configure

# 8. Start the dev server
npx expo start
```

### First things to customize

- `app.config.js` — Update `name`, `slug`, `bundleIdentifier` (iOS), and `package` (Android)
- `app/(tabs)/_layout.tsx` — Add, remove, or rename tab screens and their icons
- `tailwind.config.js` — Extend the `colors`, `fontFamily`, and `spacing` tokens to match your brand
- `global.css` — Add any global base styles alongside the Tailwind directives
- `eas.json` — Set your distribution method and build environment variables per profile
