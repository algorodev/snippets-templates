Turborepo is a high-performance build system for JavaScript and TypeScript monorepos. It caches build outputs locally and remotely so repeated tasks are near-instant, and it runs independent tasks in parallel across packages to maximize CI throughput.

## Usage

```bash
# Scaffold with the official starter
npx create-turbo@latest my-monorepo

# Or with pnpm
pnpm dlx create-turbo@latest my-monorepo
```

## How it works

The `turbo.json` pipeline defines task dependencies. Turborepo traces the dependency graph across packages and ensures `build` in downstream packages runs only after their dependencies have built — all with output caching.

```json
// turbo.json
{
  "$schema": "https://turbo.build/schema.json",
  "tasks": {
    "build": {
      "dependsOn": ["^build"],
      "outputs": [".next/**", "!.next/cache/**", "dist/**"]
    },
    "dev": {
      "cache": false,
      "persistent": true
    },
    "lint": {
      "dependsOn": ["^build"]
    },
    "type-check": {
      "dependsOn": ["^build"]
    },
    "test": {
      "dependsOn": ["^build"],
      "outputs": ["coverage/**"]
    }
  }
}
```

## Shared UI package

```typescript
// packages/ui/src/button.tsx
import * as React from "react";

export interface ButtonProps extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: "default" | "outline" | "ghost";
  size?: "sm" | "md" | "lg";
}

const sizeClasses: Record<NonNullable<ButtonProps["size"]>, string> = {
  sm: "px-3 py-1 text-sm",
  md: "px-4 py-2 text-base",
  lg: "px-6 py-3 text-lg",
};

const variantClasses: Record<NonNullable<ButtonProps["variant"]>, string> = {
  default: "bg-blue-600 text-white hover:bg-blue-700",
  outline: "border border-blue-600 text-blue-600 hover:bg-blue-50",
  ghost: "text-blue-600 hover:bg-blue-50",
};

export function Button({
  variant = "default",
  size = "md",
  className = "",
  children,
  ...props
}: ButtonProps) {
  return (
    <button
      className={`rounded font-medium transition-colors ${variantClasses[variant]} ${sizeClasses[size]} ${className}`}
      {...props}
    >
      {children}
    </button>
  );
}
```

## Express API app

```typescript
// apps/api/src/index.ts
import express from "express";

const app = express();
const port = process.env.PORT ?? 3001;

app.use(express.json());

app.get("/health", (_req, res) => {
  res.json({ status: "ok", timestamp: new Date().toISOString() });
});

app.get("/api/items", (_req, res) => {
  res.json({
    items: [
      { id: 1, name: "Item one" },
      { id: 2, name: "Item two" },
    ],
  });
});

app.listen(port, () => {
  console.log(`API server running on http://localhost:${port}`);
});
```

## README

### What this includes

- **Turborepo** — Incremental build system with local and remote caching
- **pnpm workspaces** — Fast, disk-efficient package manager with workspace linking
- **`apps/web`** — Next.js 14 app with App Router
- **`apps/api`** — Express REST API with TypeScript
- **`packages/ui`** — Shared React component library consumed by apps
- **`packages/typescript-config`** — Shared `tsconfig` base, Next.js, and Node presets
- **`packages/eslint-config`** — Shared ESLint rules across all packages
- **Parallel task execution** — `dev`, `build`, `lint`, and `test` all run across packages in parallel
- **Remote caching** — Optional Vercel Remote Cache integration for team-wide build sharing

### Prerequisites

- Node.js 18+
- pnpm 9+ (`npm install -g pnpm`)
- (Optional) A [Vercel account](https://vercel.com) for remote caching

### Create this template

```bash
# 1. Scaffold the monorepo
pnpm dlx create-turbo@latest my-monorepo

# 2. Select "pnpm" as the package manager when prompted

# 3. Enter the project
cd my-monorepo

# 4. Install dependencies
pnpm install

# 5. Start all apps and packages in dev mode
pnpm dev

# 6. Build all packages and apps
pnpm build

# 7. (Optional) Link to Vercel Remote Cache for shared CI caching
pnpm dlx turbo login
pnpm dlx turbo link
```

### First things to customize

- `turbo.json` — Add tasks for your own scripts (`test`, `e2e`, `storybook`)
- `apps/web/app/page.tsx` — Replace the placeholder home page
- `apps/api/src/index.ts` — Add your own API routes and middleware
- `packages/ui/src/` — Build out your component library
- `packages/typescript-config/` — Adjust `strict`, `target`, and lib settings
- `pnpm-workspace.yaml` — Add more workspace globs (e.g., `services/*`) if needed
