Cloudflare Workers run on V8 isolates at Cloudflare's edge — globally distributed, zero cold-start latency, and billed only for actual CPU time. This template adds KV for simple key-value storage and Durable Objects for coordinated stateful logic at the edge (think rate limiters, WebSocket rooms, or counters that need strong consistency).

## Usage

```bash
# Start a local dev server
pnpm wrangler dev

# Deploy to Cloudflare's global network
pnpm wrangler deploy
```

## How it works

The worker exports a `fetch` handler that receives every incoming request. KV is a globally-replicated key-value store accessed via the `KV` binding. Durable Objects are single-instance JavaScript classes that Cloudflare routes to a specific location for strong consistency — each object has its own storage and can handle WebSocket connections.

## Worker entry point

```typescript
// src/index.ts
import { Router } from "./router";
import type { Env } from "./types";

export { RateLimiter } from "./durableObjects/rateLimiter";
export { Counter } from "./durableObjects/counter";

export default {
  async fetch(request: Request, env: Env, ctx: ExecutionContext): Promise<Response> {
```

## Router

```typescript
// src/router.ts
import type { Env } from "./types";

export class Router {
  constructor(private env: Env, private ctx: ExecutionContext) {}

  async handle(request: Request): Promise<Response> {
    const url = new URL(request.url);
    const { pathname } = url;

    // CORS preflight
    if (request.method === "OPTIONS") {
      return this.cors(new Response(null, { status: 204 }));
    }

    try {
      if (pathname === "/") return this.cors(this.home());
      if (pathname === "/api/cache" && request.method === "GET") return this.cors(await this.getCache(url));
      if (pathname === "/api/cache" && request.method === "PUT") return this.cors(await this.putCache(request));
      if (pathname === "/api/count") return this.cors(await this.incrementCounter(url));
      if (pathname.startsWith("/api/")) return this.cors(await this.rateLimitedRoute(request, pathname));

      return this.cors(new Response("Not Found", { status: 404 }));
    } catch (err) {
      console.error(err);
      return this.cors(new Response("Internal Server Error", { status: 500 }));
    }
  }

  private home(): Response {
    return Response.json({ ok: true, message: "Cloudflare Worker running." });
  }

  private async getCache(url: URL): Promise<Response> {
    const key = url.searchParams.get("key");
    if (!key) return Response.json({ error: "key is required" }, { status: 400 });

    const value = await this.env.CACHE.get(key);
    if (value === null) return Response.json({ error: "Not found" }, { status: 404 });

    return Response.json({ key, value });
  }

  private async putCache(request: Request): Promise<Response> {
    const { key, value, ttl } = await request.json<{ key: string; value: string; ttl?: number }>();
    if (!key || !value) return Response.json({ error: "key and value are required" }, { status: 400 });

    await this.env.CACHE.put(key, value, ttl ? { expirationTtl: ttl } : undefined);
    return Response.json({ ok: true, key });
  }

  private async incrementCounter(url: URL): Promise<Response> {
    const name = url.searchParams.get("name") ?? "global";
    const id = this.env.COUNTER.idFromName(name);
    const stub = this.env.COUNTER.get(id);
    return stub.fetch(new Request("https://counter/increment"));
  }

  private async rateLimitedRoute(request: Request, path: string): Promise<Response> {
    const ip = request.headers.get("CF-Connecting-IP") ?? "unknown";
    const id = this.env.RATE_LIMITER.idFromName(ip);
    const stub = this.env.RATE_LIMITER.get(id);

    const checkResponse = await stub.fetch(new Request("https://rate-limiter/check"));
    const { allowed } = await checkResponse.json<{ allowed: boolean }>();

    if (!allowed) {
      return Response.json({ error: "Rate limit exceeded" }, {
        status: 429,
        headers: { "Retry-After": "60" },
      });
    }

    return Response.json({ ok: true, path });
  }

  private cors(response: Response): Response {
    const headers = new Headers(response.headers);
    headers.set("Access-Control-Allow-Origin", "*");
    headers.set("Access-Control-Allow-Methods", "GET, PUT, POST, DELETE, OPTIONS");
    headers.set("Access-Control-Allow-Headers", "Content-Type, Authorization");
    return new Response(response.body, { status: response.status, headers });
  }
}
```

## Durable Object: rate limiter

```typescript
// src/durableObjects/rateLimiter.ts
import type { DurableObjectState } from "@cloudflare/workers-types";

interface RateLimitState {
  count: number;
  windowStart: number;
}

export class RateLimiter {
  private state: DurableObjectState;
  private readonly limit = 60;        // requests per window
  private readonly windowMs = 60_000; // 1 minute

  constructor(state: DurableObjectState) {
    this.state = state;
  }

  async fetch(request: Request): Promise<Response> {
    const url = new URL(request.url);

    if (url.pathname === "/check") {
      const now = Date.now();
      const stored = await this.state.storage.get<RateLimitState>("state");

      let { count, windowStart } = stored ?? { count: 0, windowStart: now };

      // Reset window if expired
      if (now - windowStart > this.windowMs) {
        count = 0;
        windowStart = now;
      }

      const allowed = count < this.limit;
      if (allowed) count += 1;

      await this.state.storage.put("state", { count, windowStart });

      return Response.json({
        allowed,
        remaining: Math.max(0, this.limit - count),
        resetAt: new Date(windowStart + this.windowMs).toISOString(),
      });
    }

    return new Response("Not Found", { status: 404 });
  }
}
```

## Durable Object: counter

```typescript
// src/durableObjects/counter.ts
import type { DurableObjectState } from "@cloudflare/workers-types";

export class Counter {
  private state: DurableObjectState;

  constructor(state: DurableObjectState) {
    this.state = state;
  }

  async fetch(request: Request): Promise<Response> {
    const url = new URL(request.url);

    if (url.pathname === "/increment") {
      const current = (await this.state.storage.get<number>("count")) ?? 0;
      const next = current + 1;
      await this.state.storage.put("count", next);
      return Response.json({ count: next });
    }

    if (url.pathname === "/reset") {
      await this.state.storage.put("count", 0);
      return Response.json({ count: 0 });
    }

    const count = (await this.state.storage.get<number>("count")) ?? 0;
    return Response.json({ count });
  }
}
```

## README

### What this includes

- **Wrangler CLI** — Local dev server, deployment, secret management, and KV/DO tooling
- **TypeScript** — Full type safety with `@cloudflare/workers-types`
- **KV storage** — Globally-replicated key-value store with optional TTL
- **Durable Objects** — `RateLimiter` class (sliding-window rate limiting per IP) and `Counter` class (strongly-consistent distributed counter)
- **Router** — Lightweight URL-based request dispatcher without a framework dependency
- **CORS middleware** — Applied to all responses in a single wrapper

### Prerequisites

- Node.js 18+
- pnpm / npm
- A [Cloudflare account](https://dash.cloudflare.com/sign-up) (free tier works)

### Create this template

```bash
# 1. Scaffold a new Worker
pnpm create cloudflare@latest my-worker
# Select: Hello World Worker → TypeScript → No to deploy now

# 2. Enter the project
cd my-worker

# 3. Install types
pnpm add -D @cloudflare/workers-types

# 4. Create the KV namespace (run once per environment)
pnpm wrangler kv namespace create CACHE
# Copy the returned id into wrangler.toml [[kv_namespaces]]

pnpm wrangler kv namespace create CACHE --preview
# Copy the returned preview_id into wrangler.toml

# 5. Add Durable Object bindings and migrations to wrangler.toml (see above)

# 6. Set secrets
pnpm wrangler secret put API_SECRET

# 7. Start local dev
pnpm wrangler dev

# 8. Deploy
pnpm wrangler deploy
```

### First things to customize

- `wrangler.toml` — Replace `name`, KV namespace IDs, and add any additional bindings (R2, D1, Queues)
- `src/types.ts` — Add or remove bindings to match your `wrangler.toml`
- `src/router.ts` — Replace example routes with your own API endpoints
- `src/durableObjects/rateLimiter.ts` — Adjust `limit` and `windowMs` for your rate-limiting policy
- `wrangler secret put API_SECRET` — Rotate secrets per environment (`--env staging`, `--env production`)
