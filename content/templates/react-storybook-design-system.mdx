A design system foundation that treats tokens first — colors, spacing, typography, and radii are defined once in a `tokens.ts` file and consumed by both Tailwind and your components. Storybook 8 auto-generates documentation from JSDoc and PropTypes, and Chromatic catches unintended visual regressions on every pull request.

## Usage

```bash
# Run Storybook locally
npm run storybook

# Publish to Chromatic for visual regression CI
npx chromatic --project-token=<your-token>

# Build static Storybook for hosting
npm run build-storybook
```

## Example component

```typescript
// src/components/Badge/Badge.tsx
import type { ReactNode } from "react";

export type BadgeVariant = "default" | "success" | "warning" | "error" | "info";

export interface BadgeProps {
  /** Semantic intent of the badge. */
  variant?: BadgeVariant;
  /** Content rendered inside the badge. */
  children: ReactNode;
  /** Additional Tailwind classes. */
  className?: string;
}

const variantClasses: Record<BadgeVariant, string> = {
  default: "bg-neutral-100 text-neutral-700",
  success: "bg-green-100 text-green-700",
  warning: "bg-amber-100 text-amber-700",
  error:   "bg-red-100   text-red-700",
  info:    "bg-blue-100  text-blue-700",
};

/**
 * A compact label used to highlight status or category.
 * Supports five semantic variants that map to the design token palette.
 */
export function Badge({ variant = "default", children, className = "" }: BadgeProps) {
  return (
    <span
      className={`inline-flex items-center rounded-full px-2.5 py-0.5 text-xs font-medium
        ${variantClasses[variant]} ${className}`}
    >
      {children}
    </span>
  );
}
```

## Storybook story with autodocs

```typescript
// src/components/Badge/Badge.stories.tsx
import type { Meta, StoryObj } from "@storybook/react";
import { Badge } from "./Badge";

const meta: Meta<typeof Badge> = {
  title: "Components/Badge",
  component: Badge,
  tags: ["autodocs"],
  argTypes: {
    variant: {
      control: "select",
      options: ["default", "success", "warning", "error", "info"],
      description: "Semantic intent of the badge",
    },
  },
};

export default meta;
type Story = StoryObj<typeof Badge>;

export const Default: Story  = { args: { children: "Default" } };
export const Success: Story  = { args: { variant: "success", children: "Published" } };
export const Warning: Story  = { args: { variant: "warning", children: "Pending" } };
export const Error: Story    = { args: { variant: "error",   children: "Failed" } };
export const Info: Story     = { args: { variant: "info",    children: "Draft" } };

export const AllVariants: Story = {
  render: () => (
    <div style={{ display: "flex", gap: 8 }}>
      {(["default", "success", "warning", "error", "info"] as const).map((v) => (
        <Badge key={v} variant={v}>
          {v.charAt(0).toUpperCase() + v.slice(1)}
        </Badge>
      ))}
    </div>
  ),
};
```

## Chromatic CI

```yaml
# .github/workflows/chromatic.yml
name: Chromatic
on: push

jobs:
  chromatic:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0   # Required for Chromatic TurboSnap
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: npm
      - run: npm ci
      - uses: chromaui/action@latest
        with:
          projectToken: ${{ secrets.CHROMATIC_PROJECT_TOKEN }}
          onlyChanged: true   # TurboSnap — only test affected stories
```

## README

### What this includes

- **Storybook 8** with `react-vite` framework and `autodocs` tag support
- **Tailwind CSS v3** consuming shared design tokens
- **Token system** — a single `tokens.ts` source of truth for color, spacing, radius, and typography
- **Addons** — Essentials, Accessibility (`a11y`), Interactions, Controls
- **Chromatic** — Visual regression testing pre-wired with a GitHub Actions workflow and TurboSnap
- **JSDoc-driven docs** — Component descriptions and prop descriptions auto-populate the Docs page

### Prerequisites

- Node.js 18+
- A [Chromatic](https://www.chromatic.com) account and project token (free for open source)

### Create this template

```bash
# 1. Create a new Vite React-TS project
npm create vite@latest my-design-system -- --template react-ts
cd my-design-system

# 2. Install and initialise Storybook
npx storybook@latest init
# Choose: React + Vite

# 3. Install Tailwind CSS
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p

# 4. Install Storybook addons
npm install -D @storybook/addon-a11y @storybook/addon-interactions

# 5. Install Chromatic
npm install -D chromatic

# 6. Create src/tokens.ts with your token definitions (see above)

# 7. Wire tokens into tailwind.config.ts (see above)

# 8. Update .storybook/main.ts and .storybook/preview.ts (see above)

# 9. Add Tailwind directives to src/index.css
#    @tailwind base; @tailwind components; @tailwind utilities;

# 10. Run Storybook
npm run storybook
```

### First things to customize

- `src/tokens.ts` — Replace the example palette with your brand colors and spacing scale
- `tailwind.config.ts` — Map your tokens to Tailwind theme extensions
- `src/index.css` — Add custom CSS variables for theming (e.g. `--color-bg`, `--color-fg`) alongside Tailwind
- `.storybook/preview.ts` — Add a `ThemeProvider` decorator if you use context-based theming
- `.github/workflows/chromatic.yml` — Add `CHROMATIC_PROJECT_TOKEN` to your GitHub repository secrets
